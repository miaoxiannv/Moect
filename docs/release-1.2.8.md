# Moect 1.2.8

本次更新增加微信内置表情显示，并进一步改善图片恢复。

- **内置 109 种微信表情**：会话预览、引用和合并转发中的 `[捂脸]`、`[抠鼻]` 等文字可以显示为对应图标，连续表情也能正常显示。
- **导出后离线可看**：会话与朋友圈 HTML 会保存用到的内置表情，朋友圈正文和评论均支持。原始消息文字保持不变，仍可按表情名称搜索；未识别的名称保留文字。
- **更有针对性地恢复图片**：优先检查近期附件，跨目录比较文件时间，在附件较多、目录扫描超时时保留已经找到的图片样本。
- **补充图片密钥查找方式**：增加从当前微信账号配置中派生候选密钥的路径，继续进行完整校验，并保留原有查找方式、超时限制和取消功能。

图片恢复仍取决于本机缓存及可用的解密材料。遇到图片未显示，可先保持微信登录并打开相应图片，再点击 Moect 的“恢复图片读取”；已导出的文件需要重新导出。

## 下载与升级

- **安装版**：下载 `Moect-1.2.8-Setup-x64.exe`，可选择安装位置及是否创建桌面快捷方式。
- **便携版**：下载 `Moect-1.2.8-Windows-x64.zip`，完整解压后运行 `Moect.exe`，保留同级 `_internal` 目录。

支持 Windows 10 1809+ / Windows 11，64 位。升级保留已有配置、任务和聊天归档。
